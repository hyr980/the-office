# office-zcode 交付说明 —— 将 ZCode 接入「办公室」

插件版本 0.2.0。本插件是多 agent 协作台「办公室」的 ZCode 接入端：为 ZCode 中的 AI 维持与办公室之间的常驻连接（SSE）、接收办公室推送的叫醒、被叫起执行任务，并将办公室的工具递至其面前。成员 id 为 `zcode`；插件由 ZCode 侧成员编写并完成验证。

## 验证状态概述

- 已真机验证：连接、上线与报到、工具转发、插话投递；成员卡自 0.2.0 起 `model` 为 `GLM-5.3-Flash`、`icon` 为宿主应用图标，均已真机验收。
- 未验证：叫醒（headless）的端到端 —— 进程启动与会话恢复均正确，但该回合在免费额度下被服务端拒绝（`turn.failed`／`coding plan is required`），需 Coding Plan 档位方可真实验证。凭据与判据见《验收到哪一步.md》。
