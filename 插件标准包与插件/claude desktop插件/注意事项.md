# 注意事项 —— office-desktop（Claude Desktop 的代码选项卡接入「办公室」）

本文件只列**用之前必须先知道**的事。装法与用法见《使用说明.md》，原理与实现见《原理说明.md》《实现说明.md》，
验证状态见《验收到哪一步.md》。

---

## 一、适用范围与版本

- **只适用** Claude Desktop 的**代码选项卡**（其引擎自报 Claude Code **2.1.288**）。
- **不适用**云会话、WSL 会话 —— 官方写明插件在这两类会话里不可用；本插件按「只在本机会话」写。
- **换引擎版本要重新看**：插件 API 由引擎在每次加载时重铺，事件与 `$` 上的东西都可能变。

## 二、最要紧的一条：加载方式决定「工具对模型可不可见」

引擎声明里 `session.start` 那一节写着：它既「once per process for each loaded plugin, before the first prompt」，
又「once per fresh load of one」；并且 ——

> Observe. **The first is awaited: a `$.tool.register` is listed by turn one. A later one runs its hooks alone**:
> an enable, a worker respawn, or a reload.

⇒ **只有「进程启动时插件就已经在」那一次注册的工具，才会进给模型的清单**；
以「插件开发目录 ＋ 会话热重载」方式加载的，属于「**后来的那一次**」——**注册成功，但模型够不着**。

本机实测（同一台机、同一个会话）：热重载加载时，28 个工具在引擎侧注册着（`$.tool.list()` 数得到），
而给模型的清单里没有它们；改用「启动时就位」的方式并重启应用之后，28 个进清单，且**真的调得动**
（调用一次 `mcp__office-desktop__desk_status` 与 `mcp__office-desktop__list_tasks` 都有回话）。

⇒ **要 AI 真能调办公室的工具，插件必须随进程启动加载**（走《使用说明.md》「一、装」的第 1 条或第 3 条）。

## 三、两个按钮由人控制

- 「**连接／断开**」与「**上线／下线**」画在**输入框正上方那一条**上，**由人点**：
  起来不自动连、断了不自己重挂（《说明书》§1 第 1 件、§8 第 6／7 条）。
- 「下线」**不解除绑定**：地址留着，办公室里点「叫它上线」才叫得到人。
- 那一条上的绑定三档要看：显示「**目前页面不是绑定会话**」（醒目色）时，叫醒会叫到**别的会话**去。

## 四、三处不能乱动

| 项 | 为什么 |
| --- | --- |
| **`dataDir` 里那份状态**（默认 `~/.claude/office-desktop`） | 里面有**接入手续卡**：对已建过卡的 id，办公室要求接入时必须带上它，**空手会被当场回绝** |
| **门牌号端口**（默认 `19391`） | 办公室按卡上记的门牌号反推。端口被占时内核会**先等一拍再占两次**，实在占不上才退回随便挑一个 —— 那一次门牌号会变，要等下一次报到（点「上线」）办公室才更新 |
| **`kernel\office-bridge.mjs`** | 协议层，与标准包**逐字节一致**：17433 字节，md5 `d98e5f39b0504f740adee900409539ba`；改它就与标准包脱钩了 |

## 五、代价（设计使然，不是缺陷）

- **多一个常驻进程**：一个 node 进程 ＋ 两个监听端口 —— 那条常驻连接是 SSE、五个反向端点要有人监听，
  钩子模块两样都做不了。
- **改模块文件会让它掉线一次**：`hooks/register.tsx`、`hooks/hooks.json`、`.claude-plugin/plugin.json`
  这些引擎要读的文件，存一下即重载；重载把常驻进程收掉（那条 SSE 跟着断），而**新的默认不连** ——
  恢复只能由人重新点「连接」。
- **办公室后端重启过之后**，插件这边也要人重新点「连接」（再点一次「上线」）：重启后办公室的成员表是空的。

## 六、验证状态

详见同目录《验收到哪一步.md》。一句话：协议层、宿主侧那半、叫醒与插话落进真会话、工具真名与可见性、
人按两个按钮的效果，都在**真实办公室**上实测过。

**仍未验**：界面那一下正式装（`+` → Plugins → Add plugin；效果已由「启动时加载」达到，只是未在面板里登记）；
`claude plugin validate`／`claude plugin test`／`tsc -p` 三条命令行自检（本机无 `claude` 命令）；
插话的打断效果；云／WSL 会话；以及成员卡上 `model` 与本次会话转写里模型名不一致那一条存疑。
