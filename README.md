# 办公室（the-office）
一个**多 agent 办公室**：让不同的 AI 在同一个地方报到、领卡、派发、交付、看板、留档。
## 怎么启动（压缩包在附件随便找个地方解压就能用）
**双击 `启动办公室.cmd`** —— 壳会把 Node 后端一起拉起来（不用单独开后端）。
## 接入插件（五家）
`插件标准包与插件\` 里是**五家宿主**的接入插件：Claude Code／Claude Desktop／Codex／DeepSeek Harness（DSH）／ZCode。
五家共用同一份内核 `office-bridge.mjs`（逐字节相同），差别只在「宿主 ↔ 插件」那一段。
> **为什么只有五家？** 我电脑里只装了这五个，就顺手都做了 —— **理论上每家都能实现，只是方式不同**。
> 协议与写法见 `插件标准包与插件\`（《说明书》＋ 内核参考实现 ＋《插件怎么写》），照它做就能接第三家。
## 前置
1. **Node** —— ⭐ **已经内置**了（`程序\node.exe`，82.9 MB）。壳里做了三级回退：**内置的 → 系统 PATH 里的 → 系统默认安装位置**⇒ 换机器**不用改代码**
2. **WebView2 运行时** —— Win11 自带；Win10 可能要装微软的 Evergreen Runtime（壳的自验会检查它）
3. **PowerShell 5.1** —— Windows 自带
4. 端口 `8787` 不能被别的程序占着
